# Screenshots

Images in this folder are linked from the main README.

Every image here has been redacted: product names, categories, brands, stock
levels, prices, counterparty names and report totals are blurred, as is the
manufacturer logo visible on the packaging in the product photo. Timestamps,
interface labels and layout are left readable, since they carry no business
data and show how the bot is structured.

| File | Shows |
| --- | --- |
| `main-menu.png` | Main menu after `/start`. |
| `product-card.png` | Product card with photo, data fields and admin actions. |
| `daily-report.png` | The scheduled end-of-day report with its total. |
